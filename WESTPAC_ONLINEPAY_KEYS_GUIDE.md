# Westpac OnlinePay (Verifone Central) — Environment Keys Guide

This guide provides the exact steps to locate and retrieve all required Westpac OnlinePay environment variables from the **Westpac OnlinePay Merchant Portal (Verifone Central)**.

---

## Quick Reference Table

| Variable Name | Description | Where to find in Portal | Format Example |
| :--- | :--- | :--- | :--- |
| `ONLINEPAY_MODE` | Environment Mode | `live` for real transactions, `test` for CST sandbox | `live` |
| `ONLINEPAY_USER_UID` | API User Identifier | **Administration** $\rightarrow$ **Users** $\rightarrow$ API User profile | UUID (36 chars) |
| `ONLINEPAY_API_KEY` | API User Secret Key | **Administration** $\rightarrow$ **Users** $\rightarrow$ API Keys | UUID / Secret string |
| `ONLINEPAY_ENTITY_ID` | Merchant Entity ID | **Administration** $\rightarrow$ **Organisations / Entities** (Must match 3DS entity!) | UUID (36 chars) |
| `ONLINEPAY_PPC_ID` | Payment Provider Contract ID | **Administration** $\rightarrow$ **Payment Provider Contracts** | UUID (36 chars) |
| `ONLINEPAY_3DS_ID` | 3D Secure Contract ID | **Administration** $\rightarrow$ **3-D Secure Contracts** | UUID (36 chars) |
| `ONLINEPAY_WEBHOOK_SECRET` | Secret for payment notifications | **Generated by you** (set in both `.env` and Westpac portal) | 32+ hex chars |
| `ONLINEPAY_RETURN_BASE_URL` | Storefront HTTPS Domain | Your live storefront URL | `https://completehomesollution.com.au` |
| `NEXT_PUBLIC_APP_URL` | Storefront HTTPS Domain | Your live storefront URL | `https://completehomesollution.com.au` |

## Portal URLs

- **Live Production Portal**: [https://au.gsc.verifone.cloud](https://au.gsc.verifone.cloud) (or via Westpac Merchant login)
- **CST Sandbox Portal**: [https://cst.test-gsc.vfims.com](https://cst.test-gsc.vfims.com)

> [!IMPORTANT]
> Make sure you log into the **Live** portal if `ONLINEPAY_MODE=live`. Credentials from the Live portal do not exist in the Test CST sandbox, and test credentials do not exist in the Live portal.

## Step-by-Step Retrieval Instructions

### 1. Retrieve `ONLINEPAY_USER_UID` and `ONLINEPAY_API_KEY`

1. In the left navigation menu, click **Administration**.
2. Click **Users** (or **Users & Roles**).
3. Look for your **API / Service User** (often named `api_user`, `integration`, or similar; with role *Merchant Administrator* or *API User*).
4. Click on the API User to open its details:
   - **`ONLINEPAY_USER_UID`**: Copy the **User ID** / **User UID** field (a 36-character UUID like `12345678-abcd-1234-abcd-1234567890ab`).
   - *(Note: Do NOT use your personal email address here; it must be the API User's UID)*.
5. In the user details, navigate to the **API Keys** section:
   - **`ONLINEPAY_API_KEY`**: If an active API key is shown, copy it. If not visible or previously generated, click **Generate API Key**, copy the key immediately, and save it.

---

### 2. Retrieve `ONLINEPAY_3DS_ID` (3D Secure Contract)

1. In the left navigation menu, click **Administration**.
2. Click **3-D Secure Contracts** (or **Contracts** $\rightarrow$ **3-D Secure**).
3. You will see a table listing your active 3D Secure contract (e.g. for Visa/Mastercard 3DS).
4. Copy the **Contract ID**:
   - This value is your **`ONLINEPAY_3DS_ID`**.
5. **CRUCIAL STEP — Check the Entity column**:
   - Look at the column titled **"Entity"**, **"Merchant"**, or **"Organisation"** on that exact row.
   - Note down the exact Entity name shown here. **This entity determines your `ONLINEPAY_ENTITY_ID` in Step 4 below.**

---

### 3. Retrieve `ONLINEPAY_PPC_ID` (Payment Provider Contract)

1. In the left navigation menu, click **Administration**.
2. Click **Payment Provider Contracts** (or **Contracts** $\rightarrow$ **Payment Provider**).
3. In the list, find your active Card payment contract (e.g. Westpac Card Acquirer).
4. Copy the **Contract ID**:
   - This value is your **`ONLINEPAY_PPC_ID`**.
5. Verify that the **Entity** column on this contract matches the same entity as your 3DS contract.

---

### 4. Retrieve `ONLINEPAY_ENTITY_ID` (Merchant Entity ID)

> [!WARNING]
> **Common Pitfall**: If `ONLINEPAY_ENTITY_ID` does not belong to the entity that owns your 3DS contract, Westpac will reject checkout creation with:
> `"The entity id of the ThreeDSContract does not match the body.entityId"`

1. In the left navigation menu, click **Administration** $\rightarrow$ **Organisations & Entities** (or **Entities** / **Hierarchy**).
2. Locate the specific **Entity** that was listed beside your **3D Secure Contract** in Step 2.
   - If your account has an **Organisation** (top level) and a **Merchant/Store Entity** (child level), open the **Merchant Entity** where your contracts reside.
3. Click on the Entity (or view its properties):
   - Copy the **Entity ID** (a 36-character UUID like `87654321-dcba-4321-dcba-ba0987654321`).
4. Set this as your **`ONLINEPAY_ENTITY_ID`**.

---

### 5. Generate and Configure `ONLINEPAY_WEBHOOK_SECRET`

Westpac OnlinePay notifies your server when payments succeed or fail. To protect this endpoint from unauthorized access, a shared secret is used.

1. **Generate the secret** on your computer:
   ```bash
   openssl rand -hex 32
   ```
2. Put the generated string into your `.env`:
   ```env
   ONLINEPAY_WEBHOOK_SECRET=your_generated_64_character_hex_string
   ```
3. **Configure the Webhook URL in Westpac Portal**:
   - In the portal, click **Administration** $\rightarrow$ **Advanced Settings** $\rightarrow$ **Notifications** (or **Webhooks**).
   - Click **Add Notification** (or **Create Webhook**):
     - **URL**: `https://completehomesollution.com.au/api/webhooks/onlinepay?secret=your_generated_64_character_hex_string`
     - **Events to subscribe**:
       - `Checkout - Transaction succeeded`
       - `Checkout - Transaction failed`
     - **Payload format**: `Full event payload` (or JSON).
   - Click **Save**.

## Complete `.env` Template for Live Production

Copy and paste this template into your `.env` (and add the exact same variables to **Vercel Project Settings $\rightarrow$ Environment Variables**):

```env
# ── Payment Gateway Selection ───────────────────────────────────────────────
PAYMENT_GATEWAY=onlinepay
NEXT_PUBLIC_PAYMENT_GATEWAY=onlinepay

# ── Westpac OnlinePay (Live Mode) ───────────────────────────────────────────
ONLINEPAY_MODE=live
ONLINEPAY_USER_UID=your_live_api_user_uid_from_step_1
ONLINEPAY_API_KEY=your_live_api_key_from_step_1
ONLINEPAY_ENTITY_ID=your_matching_entity_id_from_step_4
ONLINEPAY_PPC_ID=your_payment_provider_contract_id_from_step_3
ONLINEPAY_3DS_ID=your_3ds_contract_id_from_step_2
ONLINEPAY_WEBHOOK_SECRET=your_generated_hex_secret_from_step_5

# ── Application URLs (must be HTTPS) ────────────────────────────────────────
ONLINEPAY_RETURN_BASE_URL=https://completehomesollution.com.au
NEXT_PUBLIC_APP_URL=https://completehomesollution.com.au
```

## Verification Checklist

- [ ] `ONLINEPAY_MODE` is explicitly set to `live`.
- [ ] `ONLINEPAY_USER_UID` is a 36-character UUID (not your personal login email).
- [ ] `ONLINEPAY_ENTITY_ID` matches the exact entity that owns `ONLINEPAY_3DS_ID`.
- [ ] Both `ONLINEPAY_PPC_ID` and `ONLINEPAY_3DS_ID` are under that same entity.
- [ ] `ONLINEPAY_WEBHOOK_SECRET` is set in `.env` and appended to the webhook URL in Westpac.
- [ ] If running on Vercel: variables are added in **Vercel Settings** and a **Redeploy** has been triggered.
- [ ] If running locally: local development server was **restarted** (`Ctrl+C`, then `npm run dev`).
