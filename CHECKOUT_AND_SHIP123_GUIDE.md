## What Ship123 does

Ship123 is the service the store asks for courier options, delivery prices, and shipping labels. A **Ship123 product** means a named courier service, such as Australia Post Standard or a particular DHL service; it is not a product in your store catalog. The store does **not** call Australia Post directly: even an Australia Post delivery uses Ship123's API for the quote and shipping order. A **quote** estimates the delivery charge. A **shipping order** is the later request that creates a shipment/label. Getting a quote does **not** create a shipping order or book a pickup.

The store uses Ship123's [product-list API](https://ship123-api.readme.io/reference/listavailableproductusingpost), [freight-calculation API](https://ship123-api.readme.io/reference/calculateorderusingpost), and [create-order API](https://ship123-api.readme.io/reference/createorderusingpost-1). The implementation is in [lib/ship123.ts](lib/ship123.ts).

## What will happen once an eligible courier is enabled

1. **Customer enters an Australian delivery address.** The store sends the full address and each item's packaged weight and dimensions to Ship123. It requests a quote for each named Ship123 courier service, including Australia Post services. A product without usable packaged measurements requires a manual freight quote instead of an invented price.
2. **Customer sees delivery choices in AUD.** Ship123 has returned USD quotes for this account; when it does, the store converts them using the latest matching daily USD and AUD [ECB reference rates](https://data.ecb.europa.eu/help/api/data). The store caches the rate for one hour and rejects stale or unavailable rate data. It does not add a shipping markup. If the customer has free shipping through an active membership or a discounted merchandise subtotal of at least AUD 1,200, the customer pays AUD 0 for shipping; the store still needs a real courier quote to know the order can be shipped. You, the merchant, still bear the courier cost for free-shipping orders.
3. **Customer starts payment.** The server checks product prices, stock, discounts, address, package details, courier eligibility, and the shipping charge. A normal shipping quote is signed for ten minutes and tied to that address, package set, service, and exact AUD amount. If the quote is expired or invalid, the server obtains a fresh one or asks the customer to refresh. It never trusts a shipping amount typed by the browser.
4. **Payment is confirmed.** The store first creates its own pending order and sends the customer to the OnlinePay hosted payment page. It marks the order paid only after checking the payment provider's result. **Ship123 does not automatically create a label at this point.**
5. **You create the label manually.** Open the paid order in the admin area. In **Ship123 shipping label**, select the recorded courier service and click **Create shipping label**. The store sends the sender and customer addresses and packages to Ship123, then saves the Ship123 order number. If the label is ready, use **Open label PDF**. If it is still processing, click **Refresh label** later. Tracking is saved when Ship123 returns it. Creating a Ship123 order may incur a courier charge under your Ship123 account terms; verify that with Ship123 before using a real order.
6. **You fulfil the order.** Print/use the label, arrange the courier handover or pickup as required by that service, and update the store order's fulfilment status separately. Creating or refreshing a label does not itself mark the order shipped.

## What you need to do

1. **Use the named Australia Post services already present in Ship123.** You do not need to enable another courier just to make shipping work. The store reads the account's product list automatically. `AUTO_LOWEST_PRICE` is excluded because it does not identify a specific carrier/service. If you later want another courier, ask Ship123 to enable its named product code for your API key.
2. **Confirm service details with Ship123.** Ask which Australia Post products cover domestic delivery from your sender postcode, their parcel size/weight limits, pickup or drop-off process, label availability, and charges. A service appearing in the product list does not guarantee it can quote every package or destination.
3. **Check product packaging data.** Every physical catalog item/variant needs its real *packed* weight in kg and length, width, and height in cm. Check bulky furniture, multi-item orders, and remote addresses with the courier's limits. Bad or missing measurements prevent an automatic quote.
4. **Keep sender details and the API key in the server environment.** Your current `.env` passed sender validation. The required names are `SHIP_123_API_KEY`, `SHIP123_SENDER_NAME`, `SHIP123_SENDER_LINE1` **or** `SHIP123_SENDER_STREET`, `SHIP123_SENDER_SUBURB`, `SHIP123_SENDER_STATE`, `SHIP123_SENDER_POSTCODE`, and `SHIP123_SENDER_PHONE`. `SHIP123_SENDER_LINE2` and `SHIP123_SENDER_EMAIL` are optional. Add the same real values to the hosting environment before deploying; a local `.env` does not configure production. Never put the API key in a browser, screenshot, or ticket.
5. **Run an end-to-end test before taking live orders.** Use a representative test cart and Australian address; check that a named Australia Post service returns an AUD quote and that the displayed price equals the stored order price; complete a sandbox payment; then create and open the label from the admin order page. Check that the label, sender, recipient, parcel details, and any tracking number are correct. Do not create a real Ship123 shipping order merely to test a quote unless Ship123 confirms it is safe and free.
6. **Complete deployment checks separately.** The local test database has the additive Ship123 migration, but the intended hosting database also needs `npm run db:deploy` before that release serves traffic. Production payment webhooks, public domain/TLS, shared rate limiting, email/notification delivery, and the wider [production-readiness audit](reports/production-audit-2026-09-21/PRODUCTION_READINESS.md) still require acceptance. The sample quote does not prove that a paid checkout or real label will succeed, nor does it certify the whole site for production.

## If something goes wrong

| What you see | Meaning and next step |
|---|---|
| “No named shipping service” or `available: false` | Check that Ship123 still lists a named courier product for this API key; then retry or contact Ship123. |
| No quote for one address or package | Check the full address, packed measurements, and that courier's coverage/limits. Ask Ship123 about that route. |
| Shipping price changes at payment | The address, cart, rate, or ten-minute quote changed. Refresh delivery options and retry. |
| FX/Ship123 unavailable | The store stops checkout rather than charging an unverified delivery amount. Retry after the service recovers. |
| Label not ready immediately | Open the admin order later and click **Refresh label**. The Ship123 order number is already saved. |
| Label creation timed out or says outcome uncertain | **Do not click Create again.** Search Ship123 using the store order ID as `customerOrderNo`. If a matching shipping order exists, enter its Ship123 order number in the admin panel to attach it. This prevents duplicate shipments/charges. |

This guide describes the code and account state checked on 10 October 2026. Availability and courier charges can change in Ship123; verify both before accepting real orders.
